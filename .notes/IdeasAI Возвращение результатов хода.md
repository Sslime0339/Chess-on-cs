В перечисление (enum) или класс MoveResult нужно добавить все возможные исходы хода, которые влияют на правила и состояние шахматной партии.
Вот готовая и структурированная схема того, что должно быть в этом результате:
## 1. Перечисление (Enum) для базовых исходов
Это самый простой и лаконичный способ. Функция MakeMove возвращает один из этих статусов:

public enum MoveResult
{
    // Ход невозможен (фигура так не ходит, мешают другие фигуры, или король под шахом)
    IllegalMove,   

    // Обычный успешный ход
    Success,       

    // Ход успешный, и вражескому королю объявлен шах
    Check,         

    // Мат! Игра завершена победой текущего игрока
    Checkmate,     

    // Пат (нет доступных ходов) — ничья
    Stalemate,     

    // Ничья по другим причинам (трикратное повторение, правило 50 ходов, нехватка фигур)
    Draw           
}

## 2. Структурированный класс (если нужно больше данных)
Если вашему графическому интерфейсу (UI) или звуковому движку нужно знать детали хода (например, проигрывать звук взятия фигуры или превращать пешку), лучше сделать MoveResult классом:

public class MoveResult
{
    // Статус хода (используем enum из списка выше)
    public MoveStatus Status { get; set; } 

    // Была ли взята фигура? (Нужно для звука "взятие" и правила 50 ходов)
    public bool IsCapture { get; set; }    

    // Была ли это рокировка? (Нужно для анимации движения ладьи)
    public bool IsCastling { get; set; }   

    // Требуется ли превращение пешки прямо сейчас?
    public bool NeedsPromotion { get; set; } 

    // Ссылка на фигуру, которую съели (если нужно убрать её с доски в UI)
    public ChessPiece CapturedPiece { get; set; } 
}

## 💡 Совет по реализации
Если ход игрока некорректный (IllegalMove), не меняйте состояние доски внутри MakeMove. Сразу возвращайте этот статус, чтобы UI вывел предупреждение или вернул фигуру на место.

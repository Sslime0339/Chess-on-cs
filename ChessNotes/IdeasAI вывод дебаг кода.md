В языке C# для этого лучше всего использовать директиву условной компиляции #if или атрибут [Conditional].
В режиме Debug (отладка) информация будет выводиться, а в режиме Release (готовая программа) этот код автоматически исключится при сборке и не повлияет на скорость работы программы.
Ниже подробно описаны оба способа.

------------------------------
## Вариант 1. Директивы #if и #endif (Классический)
Этот способ полностью исключает код из финальной сборки. Если символ DEBUG не определен, компилятор просто проигнорирует строчки внутри блока.

using System;
class Program
{
    static void Main()
    {
        Console.WriteLine("Этот текст выводится всегда.");

#if DEBUG
        Console.WriteLine("ОТЛАДКА: Этот текст виден только в Debug-режиме.");
#endif

        Console.WriteLine("Этот текст тоже выводится всегда.");
    }
}


* Плюс: Можно скрывать любой сложный код, инициализацию тяжелых переменных или целые блоки логики.
* Минус: Код может выглядеть визуально загроможденным, если таких проверок очень много.

------------------------------
## Вариант 2. Атрибут [Conditional] (Более чистый код)
Вы можете вынести всю отладочную печать в отдельный метод и пометить его специальным атрибутом [Conditional("DEBUG")].

using System;using System.Diagnostics; // Обязательно для работы Conditional
class Program
{
    static void Main()
    {
        Console.WriteLine("Начало программы.");

        // Этот вызов исчезнет из Release-сборки автоматически
        LogDebug("Переменная x = 10"); 

        Console.WriteLine("Конец программы.");
    }

    [Conditional("DEBUG")]
    static void LogDebug(string message)
    {
        Console.WriteLine($"[ОТЛАДКА] {message}");
    }
}


* Плюс: Код внутри метода Main остается чистым и легко читается. Вам не нужно писать #if на каждую строчку. Если собирать в Release, компилятор сам удалит все вызовы метода LogDebug из кода.
* Минус: Метод, помеченный этим атрибутом, должен обязательно возвращать void.

------------------------------
## Как это тестировать в Visual Studio / Rider?
По умолчанию при запуске проекта в вашей среде разработки уже выбран режим Debug. Чтобы проверить, что отладочная информация исчезает:

   1. Найдите на верхней панели инструментов выпадающий список конфигураций (там написано Debug).
   2. Переключите его на Release.
   3. Запустите программу. Отладочный текст больше не появится в консоли.
